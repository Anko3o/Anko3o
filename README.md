## 🧰 开源的零件

### ✦ [music-mcp-netease](https://github.com/Anko3o/Music-Mcp-Netease)

一台为人和 AI 一起听歌改造的自部署轻量网易云播放器。

AI 可以搜歌、发可点的歌曲卡和歌词卡、把歌插进播放队列，也能翻批注本、看最近在听什么；播放器这边有网易云账号同步、逐字歌词、MV 画中画和共享歌单。**纯 Python 标准库 + 原生 JS，零依赖，一条命令启动。**

### ✦ [stardust-spoiler](https://github.com/Anko3o/stardust-spoiler)
仿 Threads 的**把文字藏起来**效果：隐藏的部分是粒子星尘，点击后文字显现。

单个HTML文件，百来行。零依赖、零安装、零构建，查看其源代码就是全部。

### ✦ [anko-ob-original-archive](https://github.com/Anko3o/anko-ob-original-archive)
给 OmbreBrain 记忆库 做的**原文永存**工具。

脱水后的摘要只当索引，原文一句不删地存进侧车档案馆，随时能展开看到当初那句话本来的样子。记忆可以压缩，但不该被改写。

### ✦ [tmux-tutou](https://github.com/Anko3o/tmux-tutou)
**这是一套粉色兔子 tmux 主题。**

状态栏会说三件事：这个会话开着几个窗口、每一格里跑着什么、机器还剩多少内存。零插件、零依赖，四十来行，不改任何按键绑定。
终端不一定非得是黑的。
